## Products I've built

### Stackivo · [stackivo.me](https://stackivo.me)
One workspace for Indian freelancers, replacing the separate tools they use to run their business. It has five modules:
- **Invoicing**: create and send invoices
- **Contracts**: draft and manage client agreements
- **Client portal**: one place for clients to see their work and bills

Built for the Indian market, against tools like Refrens and Zoho Invoice, with a free tier and a paid Pro plan. I've written most of the code since the first commit, and I also own the product and the go-to-market plan.

## AI projects & hackathons

### [Enterprise Knowledge Engine](https://github.com/akshat-ships/Enterprise-Knowledge-Engine)
Built in a team for an applied AI challenge with a problem statement from EY. It answers employees' questions from company knowledge and checks each answer before showing it. Features:
- **Answer verification**: flags answers that rely on outdated values
- **Expert capture**: guided interviews that turn what senior staff know into searchable knowledge
- **Teams import**: brings in Microsoft Teams chat history
- **Evaluation**: answers scored by an independent LLM judge

**My part:** deployment and scalability. I set up the container deployment on Railway, ran the load tests, sized the database pool and answer queues so several people can use it at once, and handled LLM provider rate limits.

### Galla: Paytm × Sarvam AI hackathon · [live app](https://paytmgalla.streamlit.app/)
Built with a team of five for the "Growth Merchant AI" track. Galla works through the Paytm Soundbox: it helps kirana store owners save money and win back customers who stopped coming. I built and presented the business case: market, go-to-market, business model and pilot plan.

### Myntra Fashion Assistant · [live app](https://team01-myntra-rag-chatbot.streamlit.app/)
A team-built RAG shopping assistant on a mock Myntra catalogue. You describe what you want and it finds matching products. I worked on stress-testing it and improving the backend.
